# frontend/AGENTS.md

The React app. Different toolchain from the backend (npm/Vite/FSD/Tailwind), hence its own file.
Read the root `AGENTS.md` first for the big picture and the contract seam.

## Stack

React 19 · TanStack Router (file routes) + Query · Tailwind v4 (`@theme`, CSS-first) · radix-ui +
cva shadcn-style primitives · react-hook-form + zod · orval-generated client · vitest + MSW ·
Playwright. npm only, every version pinned exact (`.npmrc` `save-exact=true`), Node ≥22.12.

## Feature-Sliced Design — enforced

Layers, strictly downward: `app → pages → widgets → features → entities → shared`. Every slice has a
public `index.ts`; import other slices only through it. Segments within a slice: `ui model api lib
config`.

- **`src/processes/` is banned** — "process" means the BPMN model here. The step rail is
  `widgets/leasing-progress`, never `process-view`.
- **entities own reads, features own writes** (one mutation + one invalidation each); widgets compose
  features; pages compose widgets; routes (`app/routes/`) hand plain props to router-free pages.
- **Only `entities/*/api` and `features/*/api` may import `@/shared/api/generated`.** Everything else
  goes through a slice's public API.

Enforced by: `steiger` (`npm run lint:fsd`, `--fail-on-warnings`), ESLint `no-restricted-imports`
(processes ban, generated-client restriction, no deep cross-slice), and `knip` (`npm run
lint:deadcode`). Disabled steiger rules are documented with reasons in `steiger.config.ts`.

## The generated client

`src/shared/api/generated/` is generated by orval from `../openapi/openapi.json` and **committed**
(lint/knip/steiger-ignored). Never edit it by hand. After a backend contract change run the
`sync-api-client` skill, or: `npm run api:generate` then fix TypeScript, and `npm run api:check` must
be clean. Requests go through the hand-written `shared/api/http-client.ts` mutator.

## Design system

Tokens live in one `@theme` block in `src/app/styles/theme.css` (canonical Miragon CI). Use the named
type utilities (`text-h1`…`text-klein`) and the palette (`blau`, `gruen`, semantic `success`/
`warning`/`danger`/`info`) — no arbitrary values. **Green is accent-only** (fails AA as text); a
vitest guard (`shared/ui/ci-guard.test.ts`) fails the build if `text-gruen` appears in a `.tsx`.
Icons: Lucide, `strokeWidth={1.75}`.

## State, forms, copy

- **Eventual consistency is the point.** Actions return 202 and the engine advances asynchronously,
  so the detail page polls at 2s while non-terminal and stops on `ACTIVE|REJECTED|CANCELLED`
  (`isTerminal`). Don't "fix" this away — it's the BPMN lesson.
- **Query keys** come from orval; `entities/leasing-application/api/keys.ts` adds the `all`
  invalidation prefix (unit-tested).
- **Forms** are react-hook-form + `zodResolver(SubmitLeasingRequestBody)` reusing the generated
  schema. The submit form must **not** validate `age>=18` or `income>=1500` — those are DMN decisions.
- **Copy** lives in the frozen `shared/i18n/de.ts`; components never hard-code German. The tone is a
  fitness function (`de.tone.test.ts`): lowercase starts, no "Sie", proper umlauts, no em-dashes.
- **No auth.** The two seams for a fork that adds it: `app/providers` (route guards) and
  `shared/api/http-client.ts` (header injection).

## Commands

`npm run verify` runs `format:check → lint → lint:fsd → lint:deadcode → typecheck → test`. Other
scripts: `dev build typecheck test api:generate api:check e2e`. e2e specs are in `frontend/e2e/`
(inside the package so Node resolves `@playwright/test`); they drive the real app against a running
backend, with `e2e/helpers/engine-rest.ts` for timers and the form-only task.
