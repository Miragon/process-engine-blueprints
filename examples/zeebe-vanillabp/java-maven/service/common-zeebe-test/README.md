# 🧪 common-zeebe-test

**Common Zeebe Test** provides shared test support for testing BPMN processes with Camunda 8 and
VanillaBP.

## 📌 What's Included

- **WorkflowDeploymentTestConfiguration**: VanillaBP's Camunda 8 adapter deploys the BPMN models and
  opens its job workers once, when the application is ready. `@CamundaSpringProcessTest` creates a
  fresh client per test, so this configuration repeats the deployment for every test client.

The typed flow nodes and `PathWalk` walks generated by bpmn-to-code hand their element ids to
`CamundaAssert` directly (`hasCompletedElementsInOrder(walk.getIds())`), so no assertion helper is
needed on the Java side.

## 🔧 How to Use

Include **common-zeebe-test** as a test dependency and import the test configuration:

```xml
<dependency>
    <groupId>io.miragon.blueprint</groupId>
    <artifactId>common-zeebe-test</artifactId>
    <version>${project.version}</version>
    <scope>test</scope>
</dependency>
```

```java
@SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.NONE)
@CamundaSpringProcessTest
@Import(WorkflowDeploymentTestConfiguration.class)
class YourProcessTest {
}
```
